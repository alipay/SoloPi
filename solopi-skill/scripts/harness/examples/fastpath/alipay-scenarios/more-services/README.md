# 支付宝更多服务往返

从真实支付宝首页开始，第一段在“搜索框／更多／我的”中选择“更多”；第二段在“返回／搜索／最近使用”中选择“返回”。每段都采集新页面，使用节点绑定动作。独立检查“更多服务”标题、返回入口和恢复后的首页“更多”。结束清理只做首页验收。

选择器来源：`output/fastpath-cases-20260928/discover-home.json` 与 `discover-more-current.json` 的 Observation。最近使用文字映射到可点击父容器；不把切换该标签计为独立业务页面。

规则对照使用相同候选与 Oracle，以 exactText 选“更多”和“返回”；Laya 不读取 exactText。案例不提交搜索、不打开支付服务。
