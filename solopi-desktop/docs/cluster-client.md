# Desktop 实验室连接（源码候选）

在设置 → 实验室连接填写 Server 地址、组织和项目，以及可选的本地电脑备注。HTTPS 使用管理员提供的公开 CA 验证开发证书，保持 TLS 校验。用户明确选择的内网 HTTP 开发部署无需 CA，但认证信息会明文传输；该入口必须实际提供 Client API，不能把任意只读网页当作注册服务。

两按钮增量的目标是：测试连接不保存或注册；开始注册自动校验并保存配置，注册成功后自动连接和心跳，按钮切换为取消注册。取消请求先停止心跳，服务端确认后才显示已注销；超时或失败保留取消意图供重试，重启不恢复心跳。无需填写管理 token，身份和会话凭据只保存在主进程，不能复制到另一台电脑。

0.1.147设置页以两按钮操作：注册/取消期间显示旋转加载并禁用，测试不保存或注册。取消先停止心跳，服务端确认后才允许显式重注册；响应丢失或重启无会话时用本机密钥查询终态，未知/待审批不当注销成功，不自动重新注册。保留已有installationId、密钥及Server/scope绑定，不删除、复制或自动迁移。0.1.146旧候选仍包含保存与审批步骤。

重启复用本机身份；停用停止连接；吊销不会自动注册新身份。已有身份不能静默切换 Server 或 scope。代理适配和 Linux 实机验证仍有边界，连接错误应按明确错误类别处理，不能绕过证书验证。

当前阶段仅注册、会话和心跳，不含设备执行、媒体或完整跨机调度。源码通过不等于已安装或已完成真实注册；可安装版本及现场验收单独交付。

### 0.1.146 路由兼容
新设置默认 `apiMode: "cp"`，HTTP 与 HTTPS 均逐项映射 Client 白名单路由（含持钥会话注销）；服务器根地址不含路径。旧存量配置未声明模式时，HTTPS 保留 `v1`，HTTP 保留 `cp`。高级兼容选择可用于尚未注册的旧版直连服务；注册后禁止切换模式和身份归属。不探测失败后自动重发注册。HTTPS 正常校验证书，新公开域名使用系统信任，CA 留空。已有旧 Server 身份须先处理原申请及受控迁移，不删除身份文件。
