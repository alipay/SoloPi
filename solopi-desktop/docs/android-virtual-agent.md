# Android Agent 后台屏幕（实验功能）

从 GitHub 导入后台屏幕工具与恢复存储，接入本地现有 DeepSeek HarnessRuntime。默认关闭；设置位于“设置中心 → Agent 后台屏幕”，也可从 Agent 会话列表底部进入。旧版模型预算、流式对照及 AgentRuntime 不恢复。

需要支持虚拟屏幕协议的 Android SoloPi 构建、Python 3.9+、ADB 与顶部已选 Android 手机。节点与手机本地 OCR 文字会提供给当前模型；截图只在本地保存与预览。配套 Python 源码位于 resources/device-harness；安装包中复制为 harness。

每次新任务启动时冻结设备和固定验收条件。运行中改变顶部设备或设置不会转移正在执行的动作。后台屏幕模式仅开放副屏操作和本地回执读取；不开放宿主 Shell、文件写入或 Skills。压缩与工具输出裁剪继续使用现有原生 Harness，完整回执保留。

结束、停止、模型异常与退出时会清理屏幕。清理未确认时阻断下一轮操作，界面提供“重试清理”；设备确认释放并且清理状态落盘之后，才删除该会话的加密恢复记录。重启不重放未知动作，只允许按原会话恢复清理。固定验收为空时不宣称测试通过。

“消息自动回复”当前为上游受控测试应用的实验能力，需要配套 fixture APK 和控制服务；不能当作任意第三方聊天应用的可用自动回复。设置文字/视觉模型和知识库后，界面会展示此次测试范围再启动。运行进入测试任务列表；消息历史、发送不确定状态与证据保存在本地，未知发送不自动重发。模型调用复用本地请求实现，并仅为新增 reply-text/reply-image 用途增加不跟随重定向和诊断隐私保护。

本批仅完成隔离测试与构建检查，未在真实设备验证上述实验功能，也未更换手机 APK 或发布安装包。
